# 한국어 표기 보완

모델 생성 지침과 기존 대화의 표시 교정을 분리한다. 새 응답은 COMMON에서 조사 붙여쓰기·의존 명사 띄어쓰기·맞춤법을 확인하도록 지시한다. 화면에서는 의미가 명확한 공백만 교정한다. 별도 교정 모델, 사전 다운로드, 외부 맞춤법 API를 추가하지 않는다.

## 적용 범위

- `불명확 으로` → `불명확으로`, `부족 이나` → `부족이나`처럼 긴 조사 앞 공백.
- 명사 목록에 포함된 표현의 짧은 조사 앞 공백. `하지만 이 조건` 같은 독립 단어를 무조건 붙이지 않는다. 이/가 등의 받침 조건이 맞지 않거나 지시어로 읽힐 수 있는 경우는 강제 교정하지 않는다.
- 실제 Qwen smoke에서 남았던 `PoC 를` → `PoC를` 및 지정된 AI/LLM/SaaS/MVP 등의 약어 뒤 조사. 임의 식별자·모델명에는 확장하지 않는다.
- 지정한 활용형의 `확인할수 있습니다` → `확인할 수 있습니다`. 만큼/뿐/대로를 일괄 붙이지 않고, 문맥 없이 되/돼·안/않 등을 치환하지 않는다.
- 기존 내부 규칙 참조 제거 후 남는 `효율성 (p1:r1) 을`의 표시 공백도 교정한다.

공개·비공개 말풍선, 동료 발화 미리보기, 리포트와 사후 판단 요약에 적용한다. 원문 문자열과 저장 JSON, 카드/근거, 사용자 메시지/입력칸, 감사용 원문은 수정하지 않는다. 인용문·백틱·코드 블록·URL·숫자는 보존한다. 줄바꿈을 없애거나 다른 문장으로 재작성하지 않는다. 모듈 로드에 문제가 생기면 기존 표시 함수로 돌아가도록 설계했다.

이 규칙은 형태소 분석기나 전면 맞춤법 검사기가 아니다. 모델에 표기 확인을 지시해도 모든 문장의 오류가 사라진다고 보장하지 않는다. 의미가 모호하거나 실제 인용일 수 있는 내용을 강제 치환하는 것보다 보존을 우선한다. 가설·조건·근거 수준·동의 여부를 바꾸는 교정은 이 범위에 포함하지 않는다.

## 근거

국립국어원 [한글 맞춤법 제41항](https://www.korean.go.kr/kornorms/m/m_regltn.do)은 조사를 앞말에 붙여 쓰도록 규정한다. 같은 해설은 `만큼`의 조사/의존 명사 쓰임도 구별한다. 이 규범을 참고하되, 문법 역할을 구별하지 않는 전체 공백 삭제는 사용하지 않는다.

## 확인 방법

```powershell
node tests/frontend_korean.test.cjs
./.venv/Scripts/python.exe -X utf8 -m pytest -q -p no:cacheprovider
./.venv/Scripts/python.exe -X utf8 scripts/context_budget_check.py
```

33개 표시 테스트는 오교정 방지, 원문·식별자·숫자·줄바꿈 보존, 동일 입력 재교정의 안정성, 기존 ID 표시 함수와의 연결, 모듈 실패 시 기존 표시 유지, 큰 입력을 확인한다. 기존 기능96개 테스트도 다시 실행했다. 실제 브라우저는 분리된8001 합성 표시 샘플로 확인했으며, 모델 품질 검증으로 계산하지 않는다.

실제 Qwen 한 번의 신규 추론은 COMMON 추가 후 기존 응답 스키마가 유지되는지 확인한 smoke다. 여기서 `PoC 를`가 남아 약어 표시 규칙을 추가했다. 이 단일 응답은 전면 맞춤법 정확도나 페르소나 의미 충실성의 검증이 아니다. 실제 토크나이저의 최대 입력 확인은 별도로 `examples/context_budget_spacing.json`에 저장하고 이전 v5 증거를 보존했다.

최종 명령·결과·화면·기록 보존 범위는 `examples/spacing_verification.json`과 STATUS를 따른다.
