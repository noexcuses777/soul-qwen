# SOUL 대화 깊이 — protocol 6 (2026-10-12)

## 확인한 현재 동작과 판단

v5는 참여자 n명에게 독립 답변 n회, 교차 응답 n회를 주었다. 모델이 유효한 상대 지정 질문을 출력할 때만 최대 3n회까지 진행했다. 따라서 3명에서는 대부분 6개 공개 말풍선이었다. 내용은 Qwen이 아이디어·카드·질문에서 생성했지만 대화 깊이는 유사한 순서에 묶여 있었다. 짧은 질문의 관점 비교에는 사용할 수 있으나, 가격·현재 대안·전환 장벽·실패 조건의 인과 관계를 충분히 살폈다는 보장은 없다.

## 구현 계약

1. 전원의 첫 기여를 동료 의견을 보여 주지 않고 받는다. private pre와 immutable core는 유지한다.
2. 실제 상대 지정 질문/정정을 우선 처리한다. 원질문을 벗어난 순환 질문, 반복 질문, 미확인 외부 데이터를 요구하는 질문은 가상 상대에게 넘기지 않는다.
3. 역할·현재 대안·도입 장벽·입장 차이를 기준으로 비교 상대를 고른다. 차이가 없어도 조건부 동의가 가능하며 찬반을 강제하지 않는다.
4. 새로운 근거/상충 조건이 담긴 교차 응답은 원발화자에게 돌려준다(A→B→A). 자기 판단의 유지·수정과 그 이유를 설명한다. 단순 반복/보류 응답을 확장하지 않는다.
5. 아직 설명되지 않은 조건이 있고 카드로 추론 가능한 경우, 조건별 선택·포기 조건·실제 인터뷰 확인 질문을 살펴본다. 이는 실제 가격/빈도를 만들어 답하라는 요청이 아니다.
6. 확인 질문은 최대 2n개, 원발화자 재검토와 조건 탐색은 화자당 각각 최대 한 번이다. 메시지당 안전 예산은 최대 5n개 공개 발언(3명 15, 2명 10, 1명 5)이며 처음 정한 예산/진행 cursor를 저장한다. 발언 수는 새 이유·상대 질문·미확인 정보에 따라 달라진다. 15개를 채우기 위해 발언하지 않는다.
7. 명시적 지정 답변(direct)은 한 사람의 한 답변으로 유지한다. 모두의 대화를 원하면 기본 모두·상호 대화를 사용한다.
8. 근거 부족·반복·외부 자료 필요·안전 예산·유용한 비교 완료를 종료 이유로 기록한다. 이는 이번 질문 묶음의 반환이며 세션 종료가 아니다. 같은 composer와 ‘이 쟁점 더 살펴보기’로 계속 질문한다.

원질문+자기 카드+자기 최신 공개 의견 2개+정확히 지정한 공개 부모를 제공한다. 전체 transcript는 매번 보내지 않는다. 자신의 private pre는 자기 baseline에만 남으며 동료 private 내용은 노출하지 않는다. 동료 발언/이전 의견은 가설이고 immutable core/수치 근거로 승격하지 않는다. 기존 숫자·경험·구매 확정·역할 귀속 guard와 최대 한 번 교정은 유지한다. 리포트는 사용자 요청 시 생성하며 새 대화 후에는 이전 리포트가 오래됐음을 표시한다.

실제 4B 시험에서 본문만 생성하고 reason을 생략하는 응답이 관찰됐다. Qwen chat JSON grammar는 reason, stance, unresolved_issues, reasoning_rule_ids를 필수로 요구한다. 이유가 없는 내용을 서버가 대신 만들어 붙이지 않는다. 외부 확인이나 종료를 표시한 최신 의견 뒤에 과거 미해결 조건을 다시 탐색하지 않는다. 일반 비교는 각 동료의 최신 공개 발언만 고려하며 보류된 최신 발언 대신 과거 반대 의견을 되살리지 않는다. 실제 미응답 질문의 인접 답변은 명시적 부모를 유지하며 별도로 처리한다.

## 근거와 한계

- [Schegloff, Sequence Organization in Interaction (2007), chapter 1](https://www.cambridge.org/core/books/abs/sequence-organization-in-interaction/introduction-to-sequence-organization/413348A5135F444C244AB07F7327B866): 질문–답변의 기본 순서가 확인·삽입·후속 확장으로 이어질 수 있다는 설명을 실제 상대 발화에 대한 답과 재검토 구조에 적용했다. 인간 대화의 기술적 설명이며 AI 품질을 입증하는 실험은 아니다.
- [Smit et al., ICML 2024](https://proceedings.mlr.press/v235/smit24a.html): 다중 모델 토론이 다른 prompting 방식보다 일관되게 우월하지 않고 비용·시간·설정에 영향을 받는다. 더 길다는 이유로 정확하다고 주장하지 않으며 목적 있는 확장과 상한을 둔다.
- [Zhu et al., ACL 2025](https://aclanthology.org/2025.acl-long.195/): 시험한 LLM들의 다수 의견 동조와 불확실성의 영향을 관찰했다. 첫 기여 독립성과 자기 카드/명시적 부모를 유지하며 합의 여부를 종료 조건으로 사용하지 않는다.

5n은 로컬 추론 비용을 관리하는 제품 설정이다. 논문으로 입증된 최적 발언 수가 아니다. 실제 사용자 인사이트 충분성은 Founder Usefulness, valid/unsupported insight, 실제 인터뷰 theme/barrier recall로 후속 검증해야 한다. 모의 검사와 단일 Qwen 실행은 시장 검증이나 품질 입증이 아니다.

실행/검사 결과는 STATUS.md에 기록한다. protocol 2/3 자동 인터뷰와 평가 baseline은 변경하지 않는다.
