2026-10-04 current override: [v5 continuous-chat contract](15_CONTINUOUS_CHAT_REVISION.md) supersedes v1–v4 display/start/follow-up/closure rules below. Name + segment only; selection → same normal composer; all-selected contribution/grounded peer comparison, default 2×n and maximum 3×n public turns per message; optional revision-bound report snapshot, continued chat and no automatic report per message. Earlier fixed v2/A–D and automatic v3 remain compatibility/evaluation paths. Historical measurements are not v5 validation.

Historical product revision3 used adaptive protocol v3 (docs/12); current v5 is specified in docs/15. The implemented A-D generator intentionally retains fixed v2 as its controlled baseline. A separate human pilot must compare D-v2 vs D-v3 under the same total output ceiling, frozen cards/model/ideas/seeds. Annotate reply relevance, successful clarification/repair, unanswered directed questions and early termination in addition to metrics below. No superiority claim follows from a successful v3 smoke run.

Four conditions: A Generic LLM; B Single Persona; C three independent personas (no shared messages); D Private→Group→Private. Same selected model, idea, six question topics, seed, temperature and total completion-token ceiling. Generation only is compared; preparation/judge tokens recorded separately. Include input-token cost separately: equal output ceiling does not equal equal total inference cost. Single-model sequential calls. Round topic coverage held constant. Use per-call allocation based on number of calls; halt when total ceiling reached; reserve minimum output for final calls. Default 6000 completion-token ceiling, 3 seeds.

Pilot: 30 ideas stratified by business category; 3-5 real customers per idea; independently annotated themes. Freeze cards before revealing holdout transcripts. Randomize condition order and blind judges/founders. Compare paired per-idea differences with idea-level bootstrap CI; do not treat turns as independent participants. With insufficient sample report descriptive results only.

Metrics: Valid insight count, Theme recall, Novel useful insight, False insight rate, Divergence detection, Persona consistency, Conformity rate, Founder usefulness, Cost, Latency. Calibration additions: Unsupported Insight Rate, Contradiction Discovery, Alternative Recall, Barrier Recall, Confidence Calibration (Brier, ECE). Exact annotated theme IDs are the initial transparent matching method; humans resolve semantic equivalence. Unknown reference set => null. Conformity is a human-labelled unjustified move to majority, not any stance change.

Human Gold includes independent response, expert rationale and labels; no fabricated human Gold. At least 20% double annotation, adjudicate mismatch. Synthetic demo verifies I/O only. Benefit claim gate: D improves valid useful insights without higher false/unsupported rate and acceptable cost; determine thresholds before real pilot. No claim until actual pilot results exist.
