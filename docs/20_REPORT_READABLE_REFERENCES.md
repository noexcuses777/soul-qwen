# 리포트의 근거·발언 표시

`L0`~`L4`는 원자료의 유형을 구분하는 내부 코드이며, 정확도 점수나 시장 검증 등급이 아니다. `u1`, `u2`는 대화에서 생성한 발언을 리포트 원문과 연결하는 내부 식별자다.

화면과 텍스트 내려받기에서는 다음 표현을 사용한다. 원본 JSON·API·저장된 인용 ID·발언 원문은 유지한다.

| 내부 값 | 이용자에게 보이는 표현 |
| --- | --- |
| L0 | AI 추론 · 고객 근거 미확인 |
| L1 | 공개 시장 자료 참고 |
| L2 | 제공된 고객·시장 자료 참고 |
| L3 | 실제 인터뷰 자료 참고 |
| L4 | 실제 행동 자료 참고 |
| u1 등 | 이름 · 공개 대화 1번 발언 |

비공개 사전·사후 발언은 공개 대화와 별도로 번호를 매긴다. 번호는 저장된 리포트 범위의 실제 발언 순서이며, 이름과 단계가 함께 표시되어 같은 숫자라도 구별할 수 있다. 근거 펼치기에는 연결된 발언 원문이 그대로 표시된다. 원문이 없으면 ‘발언 원문을 찾을 수 없음’으로 처리하고 인용을 만들어 내지 않는다.

자료 등록의 L0는 자료의 유형·수집 경로를 아직 확인하지 못했다는 뜻이다. 업로드한 자료를 AI가 작성했다고 단정하지 않도록 이 경우는 ‘자료 유형·수집 경로 미확인’으로 표시한다. 어떤 자료를 참고했더라도 AI 해석이나 시장 수요가 입증됐다는 의미는 아니다.

표시 로직은 순수 함수로만 처리하며 LLM 호출·추론 비용·모델 설정을 바꾸지 않는다. 합성 화면 테스트로 다섯 유형, 단계별 발언 번호, 누락 인용, 원본 JSON/인용 유지와 인용문 미변경을 검증한다. 이 테스트는 실제 페르소나 품질이나 시장 수요 평가가 아니다.
