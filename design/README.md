# 화면 시안

캔버스에서 뽑은 6개 화면의 정적 HTML이다. 브라우저에서 파일을 그냥 열면 된다.

| 파일 | 화면 | 크기 |
|---|---|---|
| `01-idea-input.html` | 아이디어 입력 | 1440 × 980 |
| `02-targets.html` | 타깃 추천·선택 | 1440 × 1460 |
| `02-1-create-target.html` | 타깃 직접 만들기 | 1440 × 1220 |
| `03-compare.html` | 고른 세 명 한눈에 보기 | 1440 × 1240 |
| `04-chat.html` | 대화 — 단체 | 1440 × 940 |
| `04-1-chat-dm.html` | 대화 — 1:1 패널 열린 상태 | 1440 × 940 |
| `05-report.html` | 리포트 | 1440 × 2340 |
| `06-empty.html` | 빈 상태 — 아이디어 없음 | 1440 × 860 |
| `07-loading-targets.html` | 로딩 — 타깃 찾는 중 | 1440 × 1000 |
| `07-1-loading-chat.html` | 로딩 — 말하는 중 | 1440 × 940 |
| `07-2-loading-report.html` | 로딩 — 리포트 정리 중 | 1440 × 900 |
| `08-error.html` | 에러 — 대화 끊김 | 1440 × 860 |

## 읽는 법

- **스타일은 전부 인라인**이다. 컴포넌트로 옮길 때 `src/styles/tokens.css`의 변수로 치환한다.
- 색은 토큰값 그대로 박혀 있다. 예: `#0A57C4` → `var(--brand)`
- 데스크톱 1440 기준만 있다. **모바일(390)은 아직 없다.**
- 내용은 예시 데이터다. 실제 카피는 CLAUDE.md의 카피 원칙을 따른다.

## 컴포넌트로 옮길 때

`02-targets.html`부터 하는 걸 권한다. 이 서비스의 공통 컴포넌트가 거의 다 들어 있다:

- `AppHeader` — 로고 + STEP 네비 (6개 화면 공통)
- `PersonaCard` — 추천 카드 (02, 02-1 미리보기)
- `AttrRow` — 라벨(mono) + 값 한 줄
- `Chip` — 중립 / 충돌 / 합의 / 다음 행동 4종
- `PersonaAvatar` — 색 + 이니셜 (색만으로 구분하지 않기 위해 이니셜 필수)
- `PageFooterBar` — 하단 고정 액션 바

이걸 끝내면 나머지 화면은 조립에 가깝다.
